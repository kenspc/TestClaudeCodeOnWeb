# 照片搜索与收藏网站

一个基于纯前端技术的照片搜索和收藏网站。

## 功能特性

- 从多个来源搜索照片
- 使用 Cookie 保存收藏的照片URL
- 无需登录，使用 Cookie 识别用户
- 首次访问时要求用户输入名字
- 查看和管理（删除）已收藏的照片

## 技术栈

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (原生)

## 设计风格

- 简约专业的设计
- 主色调：白色和浅橙色

## 如何运行

1. 克隆本仓库
2. 直接用浏览器打开 `index.html` 文件
3. 或使用本地服务器（如 Live Server）

## 项目结构

```
/
├── index.html          # 主页面
├── css/               # 样式文件
├── js/                # JavaScript 文件
└── assets/            # 静态资源
```

## 浏览器支持

- Chrome (推荐)
- Firefox
